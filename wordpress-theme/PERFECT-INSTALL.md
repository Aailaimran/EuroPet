## Installation Steps (5 Minutes)

### Step 1: Download Theme
1. Go to: https://github.com/Aailaimran/EuroPet
2. Click **Code** button (top right)
3. Select **Download ZIP**
4. Extract the ZIP file on your computer
5. Locate the `wordpress-theme` folder

### Step 2: Upload to WordPress
1. Go to WordPress Admin Dashboard
2. Navigate to **Appearance → Themes**
3. Click **Add New** button
4. Click **Upload Theme** button
5. Select the `wordpress-theme` folder (or create a ZIP first)
6. Click **Install Now**
7. Click **Activate**

### Step 3: Complete Setup (1 Minute)
After activation:
1. Go to **Pages** section
2. You'll see 8 pages already created:
   - Home
   - About Us
   - Services
   - Routes
   - Rescue a Dog
   - Contact
   - Compliance
   - Privacy Policy

3. Click each page to customize content
4. Upload your own images
5. Publish each page

### Step 4: Configure Contact Forms (Optional)
1. Go to **Settings → General**
2. Verify "Admin Email Address" is correct
3. Forms will automatically send emails to this address

## Troubleshooting

### CSS Not Showing
**Solution:**
1. Go to **Plugins**
2. Disable all plugins temporarily
3. Refresh your site
4. If it works, enable plugins one by one to find the culprit

### Forms Not Sending Emails
**Solution:**
1. Check **Settings → General** for correct admin email
2. Verify your hosting allows outgoing emails
3. Check spam folder
4. Contact your hosting support

### Page Looks Broken
**Solution:**
1. Hard refresh browser: Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)
2. Clear WordPress cache if you have a cache plugin
3. Disable cache plugin temporarily
4. Check console (F12) for JavaScript errors

### Slow Loading
**Solution:**
1. Enable WordPress cache plugin (WP Super Cache)
2. Optimize images (use plugin like Smush)
3. Disable unused plugins
4. Contact hosting for optimization
